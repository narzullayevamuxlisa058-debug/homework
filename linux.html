Linux is a free and open-source operating system built around the Linux kernel, which was first released by Linus Torvalds in 1991. Unlike closed systems like Windows or macOS, it is developed collaboratively by a global community of programmers, making it highly customizable, lightweight, and secure. Today, Linux powers the vast majority of the world's servers, cloud infrastructures, supercomputers, and even forms the foundation of the Android mobile operating system. For everyday users, it is distributed via hundreds of tailored versions called "distributions" (or distros), ranging from user-friendly desktop interfaces to specialized tools for software developers and cybersecurity experts.
